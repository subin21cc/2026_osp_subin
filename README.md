## 실습 1: Git 기본 사용 시나리오

GitHub에서 다음 흐름을 직접 수행합니다.

1. 개인 public 저장소 생성
2. `git_practice_1` 브랜치 생성
3. `README.md` 수정 후 커밋
4. `git_practice_1` → `main` 풀 리퀘스트 생성
5. 풀 리퀘스트 병합
6. 저장소 URL 제출

## 배운 내용

| 명령어 | 설명 |
| --- | --- |
| `git clone` | 원격 저장소를 로컬로 복사한다 |
| `git branch` | 특정 커밋을 가리키는 브랜치를 만든다 |
| `git checkout` | HEAD를 다른 브랜치로 옮긴다 |
| `git add` | 파일을 추적 대상으로 만들고 스테이징한다 |
| `git commit` | 스테이징된 변경 사항을 스냅숏으로 기록한다 |
| `git push` | 로컬 커밋을 원격 저장소에 반영한다 |
| `git merge` | 한 브랜치를 다른 브랜치에 병합한다 |
| `git rebase` | 커밋을 다른 기준 커밋 위로 다시 쌓는다 |
